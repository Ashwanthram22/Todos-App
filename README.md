# Todo App

A simple and clean Todo web application built with HTML, CSS, and JavaScript.

This project lets you create tasks, mark tasks as completed, delete tasks, and save your todo list in the browser using `localStorage`.

## Features

- Add new tasks
- Mark tasks as completed with a checkbox
- Delete tasks from the list
- Persist todos using browser `localStorage`
- Responsive UI using Bootstrap

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Bootstrap 4
- Font Awesome

## Project Structure

```text
.
|-- ashwanth_todos.html   # Main HTML page
|-- ashwanth_todos.css    # Styling for the app
|-- ashwanth_todos.js     # App logic and localStorage handling
```

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `ashwanth_todos.html` in your browser.

No build step or installation is required.

## How It Works

- Type a task in the input box and click **Add**.
- Click the checkbox to toggle completion status.
- Click the trash icon to delete a task.
- Click **Save** to store your latest list in browser `localStorage`.

Saved tasks are stored under the key: `todoList`.
